# Tutorials

Learning-oriented walkthroughs that take you from nothing to a working result. Each one runs the published
checkpoint, [thaitea/laya-vision](https://huggingface.co/thaitea/laya-vision), on a real photo.

For task-focused recipes ("how do I do X?") see the [How-to guides](../how-to/overview.md); for how the model
works see [Concepts](../concepts/overview.md). To run the Python tutorial, [install](../install/overview.md) the
package first; the demo needs nothing installed.

## Available tutorials

- [Your first prediction](first-prediction.md): load the checkpoint in Python, ask three typed questions about a
  photo, and read the answers, including one the model gets wrong.
- [Try the demo](space-demo.md): the published checkpoint in a Hugging Face Space, with your own image and
  questions, nothing installed.
